Vercel 원클릭 배포 패키지 생성기

별도 빌드 설정(Build Step) 없이 정적 사이트로 즉시 배포 가능한 파일 구성입니다.

Step 1. 배포용 파일 컴퓨터에 저장 (새 폴더에 함께 저장)

Vercel은 기본 진입 파일로 index.html을 인식합니다. 아래 버튼을 누르면 현재 시뮬레이터가 깨끗한 초기 상태의 index.html과 vercel.json으로 즉시 다운로드됩니다.

방법 A. GitHub 연동 배포 (가장 권장) 무료·자동배포
  1. GitHub에 새 저장소(Repository)를 생성합니다.
  2. 다운로드한 index.html과 vercel.json을 업로드(Commit)합니다.
  3. vercel.com/new에 접속해 해당 저장소를 Import합니다.
  4. Framework Preset은 Other 그대로 두고 Deploy를 클릭하면 10초 내 배포가 완료됩니다.
방법 B. 터미널 CLI 10초 배포 Git 불필요

새 폴더(예: cold-plate-sim) 안에 index.html과 vercel.json을 넣은 뒤, 해당 폴더 터미널에서 아래 명령어를 실행하세요:

npx vercel --prod
포함된 vercel.json 라우팅 및 보안 헤더 구성 
{
  "version": 2,
  "cleanUrls": true,
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
